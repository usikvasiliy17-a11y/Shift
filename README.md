# SHIFT — умный планировщик жизни

Полностью самодостаточный веб-апп в формате HTML: React и Babel
подключаются с CDN прямо в браузере, сборка (npm/vite) не нужна.
Работает как устанавливаемое PWA-приложение, в том числе офлайн
после первого открытия.

## Что внутри

```
index.html      — само приложение (весь код SHIFT)
manifest.json   — манифест PWA (иконка, имя, цвет темы)
sw.js           — service worker: кеширует приложение для офлайн-режима
icons/          — иконки всех нужных размеров (192, 512, maskable, favicon, apple-touch)
.nojekyll       — отключает обработку Jekyll на GitHub Pages (иначе папка icons может быть проигнорирована)
robots.txt      — базовый файл для поисковых систем
```

## Как опубликовать на GitHub Pages

1. Создай новый репозиторий на GitHub, например `shift-app`.
2. Загрузи в него ВСЕ файлы и папку `icons/` целиком — через
   "Add file → Upload files" в интерфейсе GitHub (можно перетащить
   всю папку `icons`, GitHub сохранит структуру).
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main`,
   папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://<твой-логин>.github.io/shift-app/`

## Проверить локально

Просто открой `index.html` двойным кликом — приложение запустится
(в первый раз нужен интернет, дальше может работать офлайн благодаря
service worker).

## Установка на телефон как приложение

Открой сайт на телефоне:
- **iPhone (Safari)**: «Поделиться» → «На экран Домой».
- **Android (Chrome)**: меню (⋮) → «Добавить на главный экран»
  (или само предложит установить — значок готов, манифест настроен).

Иконка на главном экране будет с логотипом-«браслетом ритма».

## Офлайн-режим

При первом заходе (с интернетом) приложение и все его CDN-зависимости
(React, иконки Lucide) кешируются service worker'ом. При следующих
открытиях без сети сайт всё равно откроется с последним сохранённым
состоянием. Если СОВСЕМ без сети открыть сайт в первый раз — не
получится, интернет нужен минимум один раз.

## Данные

Все события хранятся в localStorage браузера, на самом устройстве.
Между разными браузерами и телефонами данные не синхронизируются —
если это понадобится, следующий шаг — подключить облачное хранилище
(например, Supabase) вместо localStorage.

## Технические детали для тех, кто будет дорабатывать

- Дата начала 8-дневного цикла смен задаётся константой `ANCHOR` в
  начале `<script type="text/babel">` внутри `index.html`.
- Вся логика планировщика (`findStretchWindows`, `findWorkoutSlots`,
  `findTaskSlots`, `checkConflict`) — там же, в конце файла, без
  внешних зависимостей, полностью локально в браузере.
- Если нужно будет вернуться к обычной сборке (для более быстрой
  загрузки без CDN) — тот же код по структуре подходит для
  Vite-проекта, поменять нужно только способ импорта React.
